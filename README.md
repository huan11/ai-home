# AI 之家 🏠🤖

> 一站式 AI 垂直门户 —— 就像汽车之家之于汽车，AI 之家之于人工智能。

## 这是什么

AI 之家是一个 AI 领域的综合门户项目，目标是让普通用户和开发者都能在这里：

- 📰 **看资讯** —— AI 行业动态、新模型发布、产品上线
- 🧰 **找工具** —— 按场景分类的 AI 工具导航（写作、绘画、编程、办公……）
- ⚖️ **做对比** —— 主流大模型/产品的横向评测与选型建议
- 📚 **学教程** —— 从入门到进阶的 AI 使用与开发教程

## 目录结构

```
ai-home/
├── README.md
├── news/          # AI 资讯
├── tools/         # AI 工具导航（按场景分类）
├── reviews/       # 模型与产品评测对比
└── tutorials/     # 教程与资源
```
